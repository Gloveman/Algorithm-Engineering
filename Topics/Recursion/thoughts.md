# Recursion
### 재귀 문제를 해결하는 방법

1. **상태 정의하기**
재귀 함수의 '목표'과, '처음 시작하는 상태'를 잘 정의하는 것 부터 시작  
상태 정의를 그대로 따르면 어떠한 예외도 없이 문제를 해결한다고 증명해야 함.

2. **종료 조건 세우기**
원하는 순간에 값을 반환하도록 종료 조건 설정
**종료 조건을 만들 때 고려할 점**
- 매번 호출 시 들어가는 인자가 변하므로, 해당 값이 최종적으로 도달하는 위치를 생각
- '최소 단위'를 정해 더 이상 진행되지 않도록
- 현재 상황에서 더 이상 탐색을 하지 못하는 상황인지 판단하는 '추가 조건'이 필요한지 고려

3. **점화식 세우기**
- 상태 정의와 종료 조건을 가지고 모든 과정을 논리적으로 풀 수 있다는 것을 증명
- 이후 해당 흐름을 그대로 따라가며 코드 작성
- 필요 시 대입을 통해 문제가 요구하는 범위까지 설정한 가설이 맞는지 검증
